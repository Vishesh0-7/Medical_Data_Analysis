# 🏥 Medicare Provider Analytics & Anomaly Detection

An end-to-end healthcare analytics project analyzing **CMS Medicare Physician & Other Practitioners** data from **2013–2024**. This project combines **SQL, Python, PostgreSQL, Machine Learning, and Power BI** to transform over **100 million Medicare provider-service records** into actionable business insights and interactive dashboards.

---

## 📌 Project Overview

Healthcare organizations generate massive amounts of billing data every year. This project demonstrates how a Data Analyst can build a complete analytics pipeline—from raw data ingestion to executive dashboards—to answer critical business questions about:

* Medicare spending trends
* Provider utilization
* Geographic cost variations
* Procedure popularity
* Provider benchmarking
* Unusual billing behavior using anomaly detection

---

## 🎯 Business Questions

This project answers questions such as:

* How has Medicare spending changed from 2013–2024?
* Which provider specialties account for the highest Medicare payments?
* Which states have the highest healthcare spending?
* Which HCPCS procedures generate the greatest costs?
* How did provider utilization change during the COVID-19 period?
* Which providers exhibit unusual billing patterns compared to their peers?

## 📂 Dataset

The dataset used in this project is publicly available from the **Centers for Medicare & Medicaid Services (CMS)**.

**Download the dataset here:** [CMS Medicare Physician & Other Practitioners by Provider and Service (2013–2024)](<https://data.cms.gov/provider-summary-by-type-of-service/medicare-physician-other-practitioners/medicare-physician-other-practitioners-by-provider-and-service>)

After downloading, place all yearly CSV files in the `data/raw/` directory before running the ETL pipeline.

## 🚀 Getting Started

### Clone the repository

```bash
git clone <repository-url>
cd medicare-analysis
```

### Start PostgreSQL

```bash
docker compose up -d
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the ETL pipeline

```bash
python src/etl_pipeline.py
```

### Launch Jupyter

```bash
jupyter notebook
```

### Open Power BI

Refresh the dataset to load the latest warehouse data and explore the interactive dashboards.
